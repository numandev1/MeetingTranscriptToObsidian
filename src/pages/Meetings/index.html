You

                        

                            

                                
                                

                                    
                                    
                                

                                

                                    Captions label your own speech as You. Set your name and it is written into
                                    transcripts, webhooks and Obsidian notes instead. Google Meet can detect it on its
                                    own; Teams and Zoom cannot, so without it those transcripts keep saying
                                    You.
                                

                            

                        

                    


                    
                    

                        
Summaries

                        
Summaries are written by ChatGPT in your own signed-in
                            account. There is no API key.

                        

                            

                                

                                    
                                    
                                

                                

                                    Opens a ChatGPT tab on its own, sends the transcript, saves the summary, and closes
                                    the tab again. The tab is in front for a few seconds while the message is typed
                                    — ChatGPT ignores a hidden tab — then you get your place back. This
                                    sends every meeting's full transcript to ChatGPT, where OpenAI's terms and data
                                    handling apply.
                                

                            


                            

                                
                                
                                

                                    Sent with the transcript appended. Change it to alter the sections, the tone, or the
                                    language — asking for the summary in the meeting's own language works.
                                

                                

                                    
                                    
                                

                            

                        

                    


                    
                    

                        
Obsidian

                        

                            Saves every meeting as a note in your vault, alongside the text file. Requires the
                            Local
                                REST API community plugin, with its non-encrypted (HTTP) server enabled
                            — the HTTPS port uses a self-signed certificate that browser extensions cannot
                            accept.
                        

                        

                            

                                

                                    
                                    
                                

                            


                            

                                
                                

                                    
                                    
                                

                                

                                    Copy it from Obsidian → Settings → Local REST API. Stored on this device
                                    only and never synced — but like any browser data it is readable by anything
                                    with access to this Chrome profile.
                                

                            


                            

                                
                                

                                    
                                    
                                

                                

                                    A folder inside your vault, created automatically. Leave it empty to save notes at
                                    the vault root. Notes are named 2026-09-14 0930 Meeting title, so they sort
                                    by date.
                                

                            


                            

                                
                                

                                    
                                    
                                

                                

                                    Kept apart from the transcripts. Each summary links back to its full transcript
                                    note.
                                

                            


                            

                                
                                

                                    
                                    
                                

                                
Only change this if you moved the plugin off its default port.
                                

                            


                            

                                

                                    
                                    
                                

                                

                                

                                    Writes every stored meeting, and any summaries, into your vault. Notes already there
                                    are left alone, so anything you edited in Obsidian — ticked action items,
                                    added context — is safe. To replace one deliberately, use the vault button on
                                    that meeting.
                                

                            

                        

                    


                    
                    

                        
Webhook

                        
Send every transcript to your own tools. Anything that accepts
                            a webhook works directly; for anything else, an automation tool like n8n bridges the
                            gap.

                        

                            

                                
                                

                                    
                                    
                                

                            


                            

                                

                                    
                                    
                                

                            


                            

                                

                                    Request body

                                

                                    
                                    
                                

                                

                                    
                                    
                                

                                

                                    Example: simple body
                                    
{
    "webhookBodyType": "simple",
    "meetingSoftware": "Google Meet",
    "meetingTitle": "Team meeting",
    "meetingStartTimestamp": "01/15/2024, 10:00 AM",
    "meetingEndTimestamp": "01/15/2024, 11:00 AM",
    "transcript": "Priya (01/15/2024, 10:00 AM)\nHi everyone!\n\nCarlos (01/15/2024, 10:01 AM)\nHello Priya!...\n\n",
    "chatMessages": "Mohammed (01/15/2024, 10:05 AM)\nCan you share the slides?\n\nSofia (01/15/2024, 10:06 AM)\nHere's the link: ...\n\n"
}

                                

                                

                                    Example: advanced body
                                    
{
    "webhookBodyType": "advanced",
    "meetingSoftware": "Google Meet",
    "meetingTitle": "Team meeting",
    "meetingStartTimestamp": "2024-01-15T10:00:00.000Z",
    "meetingEndTimestamp": "2024-01-15T11:00:00.000Z",
    "transcript": [
        {
            "personName": "Priya",
            "timestamp": "2024-01-15T10:00:00.000Z",
            "transcriptText": "Hi everyone!"
        },
        {
            "personName": "Carlos",
            "timestamp": "2024-01-15T10:01:00.000Z",
            "transcriptText": "Hello Priya!"
        }
    ],
    "chatMessages": [
        {
            "personName": "Mohammed",
            "timestamp": "2024-01-15T10:05:00.000Z",
            "chatMessageText": "Can you share the slides?"
        },
        {
            "personName": "Sofia",
            "timestamp": "2024-01-15T10:06:00.000Z",
            "chatMessageText": "Here's the link: ..."
        }
    ]
}

Files & history

                        

                            

                                
                                

                                    
                                    
                                

                                

                                    A folder inside your browser's Downloads folder. Leave it empty to save straight
                                    into Downloads. Browser extensions are not allowed to save files anywhere outside
                                    Downloads.
                                

                                

                                    
                                    
                                

                            


                            

                                
                                

                                    
                                    
                                

                                

                                    When a new meeting is saved, older ones beyond this number drop off the list. Set it
                                    to 0 to keep every meeting.
                                

                                

                                    This only clears the extension's own copy. Notes already in Obsidian, text
                                    files already downloaded and anything already sent to your webhook stay exactly
                                    where they are — nothing this extension does removes them.
